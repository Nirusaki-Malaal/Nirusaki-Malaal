I build software, take things apart, and try to understand what makes
them work. My projects range from ML algorithms written from scratch
to reverse-engineered hardware controls and native Linux apps.

I enjoy the part where the abstraction runs out: a USB packet, a model's
math, a binary, or a stubborn bug. I also build web apps and freelance
when the project is a good fit. Most of this profile is a record of
things I got curious enough to build.
